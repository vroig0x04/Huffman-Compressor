# Example assets

The repository contains text samples that can be used to test the compressor and to compare the original and decompressed result.

## Included example files

- `quijote.txt` — original sample text
- `quijote.huff` — compressed output produced by the application
- `quijote_dec.txt` — reconstructed file for comparison

These files are useful for validating the project without needing any additional external resources.
